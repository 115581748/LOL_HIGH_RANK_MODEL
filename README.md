# 峡谷行为基准

这是 `https://115581748.github.io/LOL_HIGH_RANK_MODEL/` 的静态站点源文件。

- `index.html`：4,078 条 OCE D4+ 玩家—单局记录的完整指标仪表盘。
- `conditional-model.html`：按英雄、位置、补丁、段位、阶段和局势查询的条件模型，以及 Addy The Great#OC 的纯数据差距案例。

阶段口径为前期 0–15、中期 15–25、后期 25+；25 分钟取大龙首次刷新时点。逐局案例只与同英雄、同位置基准比较。

发布方式：

站点由仓库 `115581748/LOL_HIGH_RANK_MODEL` 的 `main` 分支根目录发布。

模型数据不包含 Riot API Key 或玩家 PUUID；本地玩家案例只发布去标识化逐局行为指标与聚合统计，不含人工评价。
