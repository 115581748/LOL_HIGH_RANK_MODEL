RiftScale - English local test build

Install and launch
  Run RiftScale-English-Setup.exe. Open RiftScale from the Windows Start menu.
  The app installs for the current user and does not need administrator access.

Using the app
  Enter a Riot ID such as PlayerName#OC in the top bar.
  Enter a Riot Developer API key, click Save key, then Load player.
  Development keys expire and are intended for private testing only.
  The app collects post-match data; positions are sampled roughly once per
  minute. This is not a live in-game tracker.

Data and keys
  Your key and player cache are kept on this computer under
  %LOCALAPPDATA%\LOLHighRankComparator. They are not included in the setup.
  The app connects directly to Riot's API when you request a player refresh.

Uninstall
  Close RiftScale, then remove %LOCALAPPDATA%\Programs\RiftScale and the
  RiftScale shortcut in your Start menu. The player cache and key are stored
  separately; remove them only if you also want to erase local test data.

RiftScale is an independent project and is not endorsed by Riot Games.
